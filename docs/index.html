Aloi

Ask in plain language. The model calls tools for live data, the numbers are worked out in code, charts are drawn in the terminal, and every figure in the answer is checked against what was fetched.

Watch a session See the tools

In French, aloi is the certified fineness of a coin. De bon aloi means genuine.

On an assay touchstone, gold is rubbed into a streak and judged against needles of known fineness. These streaks are price paths from this page's data.

How it works

From a question to a checked answer

One turn of the session at the top of this page, step by step. The model decides what to call and writes the prose; everything else is code.

    Sessions

    Ten sessions, replayed

    Each replay runs Aloi's own agent loop, tools, figure checks and renderers. Prices are simulated for this page and the model's replies are scripted from the tool results, so every line you see is what the program printed.

    Visuals

    Charts drawn with characters

    Every visual is drawn from fetched data by code, never by the model. Braille dots plot lines at four times the resolution of the text grid; half blocks draw candles; background colour carries heatmaps and market maps. The model only reads the figures behind them.

    Playground

    /chart, without the model

    The /chart command draws straight from the data source. Type a command or pick the options; tickers are separated by commas because Bloomberg tickers contain spaces.

    Periods: 1d 5d 1mo 3mo 6mo ytd 1y 2y 5y 10y. Overlays: sma20 sma50 sma200 ema20 ema50 bollinger. Panels: volume rsi macd. This page carries 283 charts drawn ahead of time; Aloi draws any ticker your data source knows.

    Checks

    Every figure, assayed

    Small models, and sometimes large ones, state numbers they did not fetch. Three checks stand between the model and what you read.

    1. Answers

      Each currency amount and percentage in an answer is compared with the data the tools returned, at the precision the answer used. Figures that are not there are listed under the answer, including figures the model worked out in its head.

    2. Charts

      show_bar_chart is the one tool that draws numbers passed in by the model. It refuses any value that is not in the data fetched so far.

    3. Unfetched answers

      If the model answers with market figures without calling any tool, or says it drew a chart it did not draw, the reply is held back and the model is sent to do it.

    The answer check, on five drafts

    Draft

    What the tools returned

    The check covers amounts with a currency symbol and percentages. It does not judge other numbers, and it cannot tell whether a fetched figure was the right one to quote.

    Commands

    Slash commands

    Some things need no model at all. A watchlist dashboard, the paper portfolio and the tool switches answer straight from your machine.

    Tools

    72 tools in nine groups

    A model with a large context window gets every group. A small local model gets the core ones, because all the tool descriptions would fill its context; /tools on <group> adds a group. Switch groups below and watch the cost of every request change, worked out the way /tools does it.

      Skills

      24 playbooks

      A skill tells the model how to carry out a piece of research step by step, and which tools to call. Run one by name, or just ask: a capable model loads the matching skill itself.

      Write your own

      Put a Markdown file in ~/.aloi/skills. A file with the name of a built-in skill replaces it.

      ---
name: fx-desk
description: Morning check of the currency majors
usage: /fx-desk [pair]
---
1. Call show_dashboard with preset "fx" over 1mo.
2. Call get_news on "currency markets" over 2 days.
3. Write three lines: the dollar, the biggest mover,
   and what to watch.

      Expert mode

      Put /deep before a question for the answer an experienced portfolio manager would give. Your model gathers the data with the tools; Claude Opus reads all of it once and decides; an investment committee reads the draft before you do, checking suitability, concentration, hindsight, what is priced in, sizing and hedge design, with a bull and a bear for trade ideas. Without it, the model you chose answers with the same tools and playbooks, for about a cent.

      Market data

      Your Bloomberg Terminal
      Through the local Desktop API, on your licence: any reference field with overrides, field history, index members and screening, option chains with the volatility smile, yield curves for ten countries. Windows only, where the Terminal runs.
      Yahoo Finance
      Free, no account, prices may be delayed. The default on macOS and Linux, and the fallback when the Terminal is not reachable.

      And free sources for what a terminal does not carry

        None needs an API key. When CoinGecko's keyless limit is spent, Aloi waits out short penalties and falls back to CoinPaprika.

        Paper trading

        The built-in paper portfolio
        $100,000 of pretend money in a file on your machine, filled at the last price.
        Your Interactive Brokers paper account
        Through IB Gateway or TWS on your machine: positions, open orders and fills, stock orders, and option orders at a limit. Paper accounts only, and every order waits for you to type y.

        /report measures how either one has actually done: the value at each close rebuilt from the trades, against a benchmark, Treasury bills and doing nothing, with a report page that opens in your browser.

        Availability

        Not available yet

        Aloi is in private testing, and there is no download yet. This page shows what it does: every terminal on it was printed by Aloi's own code.

        In a terminal it runs as aloi. The first run asks which model should answer and, on Windows, where market data should come from.

        aloichat session
        aloi "compare Nvidia and AMD over 1y"one question, then exit
        aloi /briefone skill, then exit
        aloi setupchange the model, the key or the data source
        aloi doctorcheck that the model and the data source answer
        aloi --data yahoo --model claude-sonnet-5-5override the saved choices for one session
        aloi --broker ibkrtrade your IBKR paper account instead of the built-in one

        Settings live in ~/.aloi/config.toml; ALOI_MODEL, ALOI_DATA, ALOI_TOOLS, ALOI_NUM_CTX and ALOI_THINK=1 override them for one terminal. The paper portfolio, the watchlist, saved sessions and report pages live in ~/.aloi too, and survive updates.

        Inside

        Inside the program

        agent.py
        the model and tool loop, corrections and the figure checks
        grounding.py
        matching figures in text against fetched data
        models/
        adapters for Ollama and Anthropic behind one protocol
        providers/
        Bloomberg and Yahoo behind the DataProvider protocol
        sources/
        the free sources, one module each, with caching and rate-limit handling
        tools/
        what the model can call: each tool is a schema plus a function
        skills/
        the playbooks, as Markdown
        charts/
        line, candle, panel, bar, heatmap, tile and trend-table renderers
        analytics.py
        indicators, risk statistics and other price maths
        performance.py
        the track record, rebuilt from the trades and each day's closes
        ibkr.py
        the IBKR paper account, through IB Gateway, and its journal
        committee.py
        the investment committee that reads a deep answer before you do
        evals/
        two evals: how reliably a model drives the tools, and how expert its answers are, graded against a practitioner's rubric
        • Compiled. Aloi's own code, playbooks included, is compiled to machine code with Nuitka. The build fails if any of its Python source ends up in the bundle.
        • Tested offline. Data sources are tested on saved samples of their payloads, so the suite runs without a network.
        • Measured. evals/tool_calling.py scores how reliably a model drives the tools: a case passes when the model called a fitting tool, every call was valid, and the answer had no figure missing from the fetched data.
